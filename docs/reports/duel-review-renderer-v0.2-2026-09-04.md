# 对局审阅渲染器 v0.2

## 本次修复

- 对手场地按真实俯视关系调整为魔法陷阱区在上、怪兽区在下；我方保持怪兽区在上、魔法陷阱区在下。
- 两个额外怪兽区改用与主怪兽区相同的五列网格，分别严格对齐双方的 M2 与 M4。
- 场上卡片统一使用游戏王卡片的 59:86 比例和固定尺寸，避免不同内容导致格子缩放或位移。
- 怪兽的表侧守备与里侧守备表示均横置；里侧卡继续只显示卡背，不泄露身份。
- 对局 observation 中的一基序号在渲染前转换为零基区域索引，修复卡片可能偏移一个格子的问题。
- observation 中标记为 overlay 的卡不再占用怪兽区；其素材数量显示在宿主怪兽上，并且不会重复计入区域统计。

## 支持边界

运行时审阅页现在能够显示表侧攻击、表侧守备、里侧守备、共享额外怪兽区和超量素材数量。卡片的召唤合法性、效果处理与超量召唤规则仍由 `ocgcore` 验证，渲染器只负责忠实展示 observation。

Project Ignis Lua 残局页属于静态解析：它能读取初始场地、位置和公开信息，但不会执行 Lua 中运行时发生的 `Duel.Overlay`。发现这类调用时，页面与清单会明确标记为“动态素材关系尚未静态解析”，不能把该图片当作完整的引擎验证结果。

## 验收结果

- 重新生成 30 道 Understanding、20 道 Construction 和 66 道 Puzzle，共 116 张审阅题面。
- `scripts.check_public_site` 通过：242 个公开站点文件，总大小 49,133,173 bytes。
- 审阅器、对局看板、构筑看板、公开站点和公开数据共 22 项单元测试通过。
- 人工检查了包含对手魔陷、双方怪兽、守备怪兽、手牌和共享额外怪兽区的代表性题面，未发现重叠或越界。
