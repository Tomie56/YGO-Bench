# 交互式对局审阅器 v0.1

## 交付内容

策略 Puzzle 不再只能查看合成 PNG。审阅器会从冻结的 Puzzle 初始状态生成可交互场面，并保持此前确认的垂直俯视布局、双方区域顺序、M2/M4 对齐的额外怪兽区、攻守表示和怪兽所有权边框。

- 场上卡牌支持左键或右键选择，右侧显示卡名、卡号、卡片类型、属性、种族、等级或阶级、ATK/DEF、效果文本和当前区域。
- 左侧新增额外卡组、墓地、除外区、盖放卡和超量素材五组列表；列表可以折叠，点击卡面后使用同一个右侧详情面板。
- 对手手牌、主卡组、额外卡组和里侧卡会在交互 schema 中直接移除卡号，而不是仅靠 CSS 遮挡。当前玩家的手牌、额外卡组和己方盖卡仍可按已知信息查看。
- 卡牌详情来自冻结 BabelCDB。页面只导出交互状态实际引用且身份可见的 639 张低分辨率卡图，共约 12 MiB；不会把 14,605 张原始全卡图库复制到公开站点。
- 超量素材区域已纳入统一交互 schema。Project Ignis Lua 中运行时发生、静态解析无法恢复宿主关系的 `Duel.Overlay` 会显示明确警告，不生成虚假素材关系。

## 数据与隐私检查

当前 66 个 Puzzle 共包含 1,600 个卡片实例。交互 catalog 将其中 478 个私有实例的 `card_id` 置为空值；所有剩余可见卡号均可在 CDB 详情索引中解析。公开 catalog 不包含本机绝对路径或原始 CDB 路径。

## 浏览器验收

使用 1600×1000 Edge 视口进行了真实交互检查：

- 右键场上 `Ultimate Ancient Gear Golem` 后，右侧详情正确更新；
- 点击左侧额外卡组的 `Vision HERO Adoration` 后，右侧卡图和效果文本正确切换；
- 选择包含动态 Overlay 的 Puzzle 后，超量素材列表显示未解析提示；
- 三栏边界没有重叠，页面没有水平溢出；场面和详情中的卡图均完成解码。

## 边界

该页面仍是审阅工具，不执行动作、不推进回合，也不代替 `ocgcore` 验证合法性。静态 Puzzle 的动态效果、连锁、结算和素材关系只有在接入对应 runtime loader 后才能成为引擎验证结果。
