# 交互式对局审阅器 v0.2

日期：2026-09-05

本轮修复了对局审阅页的四类可用性问题：

- 我方已知手牌不再因引擎的 `face-down` 状态标记而显示为卡背；只有场上里侧卡和对手未知卡继续隐藏身份。
- 两个额外怪兽区分别与通常怪兽区 M2、M4 严格同列。
- 双方 Deck、GY、Ban、Extra 均改为固定比例卡位；数量为 0 时保留空位，有卡时显示顶部卡牌或卡背，并可点击查看详情。
- 对局场景缩放改为实际缩放整个交互桌面，支持缩小、放大和一键复位。

## 验证结果

在 Edge 1600 x 1000 视口中完成自动化交互验证：

- 我方手牌正面卡图：3 张；错误卡背：0 张。
- 资源卡位：双方共 8 个。
- EMZ 1 与 M2 的横坐标均为 502；EMZ 2 与 M4 的横坐标均为 794。
- 资源卡位点击后成功显示 `Vision HERO Adoration` 详情。
- 场上卡右键后成功显示 `Ultimate Ancient Gear Golem` 详情。
- 对局桌面宽度可由 900 px 缩小至 720 px，并复位至 900 px。
- 页面三栏无重叠、无水平溢出，真实卡图加载正常。

浏览器资源链接增加了版本参数，避免 GitHub Pages 或本地浏览器继续使用旧版 CSS/JavaScript 缓存。

审阅器定向单元测试 4/4 通过。仓库全量测试共 86 项，其中 84 项通过，2 项既有研究状态断言失败：旧测试仍要求 Understanding 候选数为 0，以及旧 readiness 报告仍将 runtime 标记为未就绪；两项均不属于本轮界面改动。
